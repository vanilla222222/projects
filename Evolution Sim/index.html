Controls

Map
Scroll to zoom, drag to pan, click a creature, plant or swarm to inspect it
Species
Click a row, lineage entry or event to open its details
Classes
Click a class card (Fish, Amphibians, Reptiles, Mammals, Birds, Invertebrates) to see its herbivores, omnivores, predators and scavengers; the chips on the Animals tab filter the list by class
Family tree
Opens from a species' details; scroll zooms, drag pans, click a bar to select
Speed
¼× to Max; Max runs as fast as the machine allows
Seed
The same seed and size always grow the same world
Save / Load
The arrow buttons next to New world download the whole world as an .evo file and load one back, exactly where it left off
