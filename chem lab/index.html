    Shortcuts & gestures

    Drawing

    Click canvas
    Place atom or stamp
    Click near an atom
    Grow a bond (ghost preview)
    Drag from atom
    Draw bond / attach stamp
    Click bond
    Cycle single → double → triple → wedge → hash
    Right-click
    Context menu for atom, bond, molecule or canvas
    Shift+right-click
    Quick-delete atom or bond
    Shift-drag atom
    Move just that atom

    Hover an atom

    C N O S P D F L B I
    Change element (L = Cl, B = Br)
    Q
    Pick any element from the periodic table
    + -
    Raise / lower formal charge
    Del
    Delete it

    Hover a bond

    1 2 3
    Single / double / triple
    W H
    Wedge / hash (again to flip direction)
    Del
    Delete it

    Tools & stamps

    Esc
    Clear selection, drop stamp, draw tool, close panels
    V / M / E
    Select / move / erase tool
    A / U / T
    Reaction arrow / curly arrow / text label tool
    Arrow tool
    Drag to draw (Shift = free angle); click an arrow to cycle forward → equilibrium → resonance → retrosynthetic
    Curly tool
    Drag from an atom or bond to where the electrons go; ends snap to atoms and bond midpoints. Click an arrow to switch two-electron ↔ fishhook; right-click to flip the curve
    Text tool
    Click to add a label; Enter finishes, Shift+Enter adds a line; double-click a label to edit
    Element key (no hover)
    Pick element to draw with
    Q (no hover)
    Periodic table: click an element, or type and press Enter
    3–8
    Cycloalkane stamp
    Shift+6
    Benzene stamp
    /
    Search stamps

    View

    Scroll wheel
    Zoom at cursor
    Drag empty canvas
    Pan (also Space-drag, middle-drag)
    + - 0
    Zoom in / out / fit (off an atom)
    Pinch / two fingers
    Zoom / pan on a touch screen or trackpad; long-press opens the context menu
    #
    Show / hide IUPAC locant numbers on the parent chain or ring

    Insight

    Alt+L
    Lone pairs & radicals
    Alt+H
    Hybridization badges
    Alt+O
    Oxidation states
    Alt+P
    Partial-charge heat map (Gasteiger)
    Alt+A
    Most acidic / most basic site pins
    Alt+S
    Find a substructure (SMILES or name); Esc clears it
    Alt+R
    Resonance structures of the hovered or largest molecule
    Alt+N
    Predicted spectra dock (¹H/¹³C NMR, IR, MS)
    Alt+U
    "Identify the unknown" spectra puzzle
    Alt+I
    Find constitutional isomers of the selection, hovered or largest molecule
    Alt+B
    Polymer brackets around the selected repeat unit
    Alt+D
    3D model and chair, Newman, Fischer, Haworth projections
    Alt+T
    Retrosynthesis of the selection or largest molecule

    Molecule names

    Click name
    Copy it
    Right-click name
    Menu with properties, copy, transform
    Middle-click molecule
    Save as a stamp

    File

    Ctrl+Z / Ctrl+Y
    Undo / redo
    Ctrl+S / Ctrl+O
    Save / open drawing
    Autosave
    Your drawing is restored on reload
    Alt+K
    Copy a share link to this drawing
    Alt+J
    Lab notebook export (HTML, Markdown, print)

    Selecting

    Select tool drag
    Box-select atoms
    Shift-drag empty
    Box-select from any tool (adds)
    Double-click
    Select a whole molecule
    Drag selection
    Move it (Select or Move tool)
    Ctrl+A
    Select all

    Editing

    Ctrl+C / X / V
    Copy / cut / paste at cursor
    Ctrl+D
    Duplicate
    Ctrl+Shift+C
    Copy SMILES of the canvas
    ←↑→↓
    Nudge (Shift = further)
    [ ]
    Rotate 15°
    { }
    Rotate 90°
    X / Y
    Flip horizontal / vertical
    Del
    Delete selection
    K
    Clean up layout
    Drop onto atoms
    Merge overlapping atoms (hold Alt to skip)
    Paste SMILES
    Ctrl+V imports it at the cursor
