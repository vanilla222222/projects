# World One UI reference and scope

Researched 5 November 2026. References guide information architecture and interaction patterns; Wildroot uses original vector icons, window decoration, colors and character art. No Idleon image assets are shipped.

| Reference pattern | Wildroot implementation |
| --- | --- |
| Persistent Auto / Attacks / Items / Talents / Codex / Map / Players / Menu dock | Eight screen-fitting buttons, HP/MP/XP HUD, optional floating attack bar, keyboard shortcuts and touch movement |
| Character statistics, equipment/tool/food tabs beside a personal bag | Live statistics, paper doll, working gear/food/tool slots, grid pages, locks, splits, drops, comparison and shared storage |
| Talent icon grid and selected talent pane | Separate beginner/class/profession budgets, point batches, active skill assignment and two saved builds |
| Codex quests, cards and quick reference | Obtained-only quest journal with filters, personal card presets and set bonuses, facility reference with existing access rules |
| World map nodes and teleport discovery | Connected World One atlas, selected room details, real portal gates and charge-limited discovered-room teleports |
| World One telescope and constellation progression | Original three-zone Elder Tree with upward camera, summit telescope, eight physical constellation markers, ten signs and personal equipped slots |
| Early account upgrade vault | Original eight-track coin-funded Greenreach Vault using real combat/gathering/carry/AFK/coin bonuses |
| Achievements and solo challenge rewards | Fifteen one-time gem achievements and an eight-wave, ticketed single-player trial board in Legacy Square |
| Town production and crafting windows | Selected recipes, ingredient sources, blueprint requirements, favorites, anvil production, continuous furnaces, stones, runes, alchemy, shops, stamps and statues |

Excluded: chat, guild interfaces, parties and multiplayer-only activities; later-world systems such as Obols, fishing, catching, construction and worship. The World Two gate remains dormant. Existing custom class and skill plans remain in force.
