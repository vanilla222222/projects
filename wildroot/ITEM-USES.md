# World One item-use audit

199 items; every item has at least three distinct implemented roles. Selling, moving, equipping a cosmetic and duplicate descriptions do not count as additional roles. Ordinary spare items can be reclaimed at the foundry or contributed to a specific Legacy Square project. Protected tokens instead have non-consuming attunements and signature patterns.

The core transaction test executes both spare-item actions for every ordinary item, and attunement/pattern/crafting actions for all eight protected badges. An additional test checks every infusible material.
