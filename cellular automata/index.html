Ruleset

C2 = off. Above C2, anything higher adds a new buffer state for dying cells.

Generational interaction

Ignore: only fully-alive (gen 1) neighbors count, dying cells just fade out. Health: dying cells still count as full neighbors for everyone else. Independent: every generation also gets its own Born/Survive rule.

Update scheme

Standard: each cell updates from its own neighbor counts (everything above). Margolus: the grid is diced into alternating 2×2 blocks each generation, and each whole block is transformed at once — square grid only, and Born/Survive/Killed don't apply.

Margolus rule

Rotate: every block spins in place — nothing is born or dies, cell count is exactly conserved. BBM: corners swap diagonally each step — an elastic billiard-ball gas. Critters: reversible and chaotic — blocks with exactly 2 alive cells just rotate, every other block inverts and rotates. Tron: every block inverts each step — explosive, fractal growth from a single cell.

Neighborhood

Noise mode

Full: every cell is eligible. Birth: only cells born this generation. Death: only dead or dying (hurt) cells. Untouched: only cells whose value didn't change this generation.

%

Each generation, an eligible cell has this % chance to be randomly reassigned to any team/generation, or emptied.
